# Day 01 - SQL Basics Practice

## 📌 Objective

The purpose of this practice is to understand the basic SQL commands used for retrieving and filtering data from a database.

## 📚 Topics Covered

- CREATE TABLE
- INSERT INTO
- SELECT
- WHERE
- AND
- OR
- LIKE
- BETWEEN
- ORDER BY
- MAX()
- MIN()

## 🗂 Database

employees

## 📊 Records

Total Employees: 20

## 🧠 Queries Practiced

1. Retrieve all employee records.
2. Display employee name and salary.
3. Find employees from the IT department.
4. Find employees with salary greater than 50,000.
5. Find employees who joined after 2020.
6. Find employees from Kanpur or Mumbai.
7. Find employees whose names start with 'A'.
8. Find employees between age 25 and 30.
9. Sort employees by salary (descending).
10. Sort employees alphabetically.
11. Find maximum salary.
12. Find minimum salary.
13. Find Finance employees who joined before 2022.

## 🎯 Learning Outcome

After completing this practice, I learned:

- How to retrieve data using SELECT.
- How to filter records using WHERE.
- How to use logical operators (AND, OR).
- How to search using LIKE.
- How to filter using BETWEEN.
- How to sort data using ORDER BY.
- How to use aggregate functions like MAX() and MIN().
